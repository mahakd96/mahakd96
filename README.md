## Selected Projects

### Dormify – Intelligent Dormitory Allocation & Management System

**[GitHub Repository](https://github.com/mahakd96/dormify-project)**

A full-stack dormitory allocation and management system developed as a final-year engineering project in collaboration with the **Technion Dormitories Office**.

The system automates and supports complex student housing allocation processes by considering accommodation requirements, institutional constraints, student preferences, and allocation priorities.

**Key Features & Contributions:**
- Developed and refined a constraint-based allocation engine using Google OR-Tools (CP-SAT).
- Implemented and improved allocation logic, including hard and soft constraints, student priorities, and accommodation compatibility.
- Developed full-stack functionalities supporting student data import, dormitory management, and allocation workflows.
- Implemented assisted allocation mechanisms and student transfer workflows.
- Improved allocation performance, backend processing, and system reliability.
- Participated in integration testing, debugging, deployment preparation, and technical documentation.
- Collaborated with stakeholders to translate operational requirements into practical software solutions.

**Technologies:** Python, React, Django, Django REST Framework, PostgreSQL, Google OR-Tools, Docker, Microsoft Azure

### GenAI Familiarity & Student Engagement – Causal Analysis

**[GitHub Repository](https://github.com/mahakd96/genai-familiarity-student-engagement-causal-analysis)**

A data-driven research project investigating the relationship between students' prior familiarity with generative artificial intelligence and their evaluative engagement during an AI-assisted academic task.

The project explores the role of prior technological familiarity in students' interactions with AI tools through statistical analysis and causal-inference methodologies.

**Key Areas:**
- Data preparation, cleaning, and exploratory analysis.
- Statistical reasoning and research hypothesis evaluation.
- Causal inference and interpretation of relationships between variables.
- Data visualization and presentation of research findings.

**Technologies & Methods:** Python, Jupyter Notebook, Statistical Analysis, Data Visualization, Causal Inference

### Canva Magic Design – UX/UI Research & Usability Improvement

A human-computer interaction and cognitive engineering project focused on analyzing and improving the user experience of Canva's AI-assisted design functionality.

The project examined usability challenges, user expectations, and interaction design through structured research and prototype evaluation.

**Key Contributions:**
- Conducted user research and analyzed usability challenges.
- Applied Hierarchical Task Analysis (HTA) and Cognitive Task Analysis.
- Used Quality Function Deployment (QFD) to translate user needs into design requirements.
- Designed an interactive prototype in Figma.
- Conducted usability evaluations and compared user experiences across different levels of expertise.
- Proposed interface improvements to enhance clarity, user control, and interaction efficiency.

**Tools & Methods:** Figma, UX Research, UI Prototyping, HTA, Cognitive Task Analysis, QFD, Usability Testing
